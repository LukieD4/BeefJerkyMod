## 🛠️ Building From Source

Built and tested with:

| Requirement | Version |
|---|---|
| Forge MDK | `forge-1.18.2-40.3.11-mdk.zip` |
| JDK | Eclipse Temurin 17 (`17.0.18`) |

> **Note:** From version `1.0.2` onward, development has moved to **IntelliJ IDEA**.

### Using IntelliJ IDEA (recommended)

1. Open the project folder in IntelliJ.
2. Let Gradle sync automatically.
3. Run the `client` Gradle task to test in-game.

### Using VS Code

If you'd rather skip IntelliJ and use VS Code instead:

```bash
./gradlew genVSCodeRuns
```

Then:

1. Build the project with Gradle.
2. Insert `/src/` and any other relevant project files.
